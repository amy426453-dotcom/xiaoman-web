# 小满童年记忆互动网页

这是一个以“搬家前的最后一个夏夜”为主题的互动网页项目。访客可以在房间场景中探索书包、电脑、抽屉、MP3 和纸箱，触发图片、文字与音效互动。

## 项目状态

当前版本为 **MVP（最小可行产品）/ Demo 原型体验版**，用于验证整体视觉风格、房间探索流程和互动方式。项目仍在持续开发与迭代中，现有页面、文案和素材可能会继续调整。

当前 MVP 主要包含：

- 2D 房间场景与基础探索入口
- 书包、电脑、抽屉、MP3、纸箱等核心物件互动
- 图片、文字、音效和简单的模块完成状态反馈
- 基础的线性回忆体验流程

AI 对话、个性化内容生成和 3D 可探索空间不属于当前 MVP，属于后续版本规划。项目后续也会从当前的静态网页 Demo，逐步演进为动态网页，支持动态内容、用户进度、个性化互动和更实时的场景反馈。

## 后续开发方向

- 引入 AI 能力，让用户可以通过自然语言与“小满”或房间中的物件进行对话
- 基于用户输入生成个性化的童年回忆、物件故事和互动反馈
- 探索 AI 驱动的角色反应、情绪表达和多轮叙事体验
- 将当前 2D 房间逐步升级为可自由探索的 3D 场景，加入视角移动、空间探索和物件交互
- 逐步加入社交属性，让用户可以打造、布置并分享属于自己的回忆房间
- 探索访客互相参观回忆房间、交换故事和共同创造回忆内容的体验
- 补充更多房间区域、隐藏线索、回忆内容与分支结局
- 持续优化移动端适配、音频体验、进度保存和正式发布前的稳定性测试

## 本地运行

项目为静态网页，不需要构建工具。如果电脑上已经有项目文件，可进入项目目录并启动本地服务器：

```bash
cd "/Users/carmen/Documents/新"
python3 -m http.server 8000
```

如果电脑上没有项目文件，可在 GitHub 仓库页面点击 **Code → Download ZIP**，下载并解压后进入项目目录，再运行上面的命令。

服务器启动后，访问 <http://localhost:8000/web/intro.html> 进入首页，再点击按钮进入房间；也可以直接访问 <http://localhost:8000/web/room.html>。

为了更完整、稳定地呈现网页中的图片、音频和交互效果，推荐使用本地服务器运行。部分浏览器可能会限制本地资源或音频加载。

## 目录结构

- `web/`：网页 HTML、JavaScript 与 CSS
- `素材/`：网页使用的图片、音频和字体资源
- `vercel.json`：静态部署配置

## 部署

将整个项目部署到支持静态文件托管的平台，并确保 `web/` 与 `素材/` 的相对路径保持不变。

## 说明

项目中的图片、音频和字体素材仅按项目授权范围使用。未被网页引用的历史素材不纳入版本库，但可保留在本地素材备份中。
