# 童年回忆互动网页按钮视觉系统

## 目标

为“搬家前的最后一个夏夜”建立一套与暖色手绘房间、旧物收藏和手写叙事一致的网页按钮系统。按钮不使用逐张生成的图片，而由 CSS、现有“小满手写”字体和少量内置 SVG 图标实现。

## 视觉方向

采用“手写便签 + 小图标”方向：按钮像从旧房间里撕下来的纸卡，使用米白纸张、深棕字、旧纸边框和暖黄色交互反馈。按钮保持清楚可读，不模拟复杂的 00 年代软件界面，也不使用厚重木纹按钮，避免与背景家具和纸箱混在一起。

## 设计令牌

### 颜色

- 文字：`#5B402C`
- 纸卡：`#F1E4C8`
- 旧纸边框：`#B68B55`
- 推荐/悬停：`#F2C66D`
- 完成：`#D9903D`
- 禁用：`#A79B86`

### 字体

- 短按钮文字、情绪化动作文字：现有“小满手写”字体。
- 较长说明、错误提示和辅助文本：清晰的中文系统字体。
- 手写字体不用于长段落、时间、数值或需要快速扫描的信息。

## 按钮类型

- 主操作：`打开抽屉`、`把这段记忆放进去`、`收好照片`。
  - 米白纸卡底、深棕文字、旧纸边框。
  - 悬停和聚焦时出现暖黄色边缘光。
- 次操作：`这次先不放`、`返回房间`、`先留在这里`。
  - 透明背景或极浅纸色，仅保留手绘下划线和较低对比度。
- 工具操作：关闭、返回、静音、暂停、翻面。
  - 小型圆形或纸签按钮；图标旁保留文字或可读标签，不只依赖图形。
- 状态操作：`重新开始`、`再过一次夏天`。
  - 使用普通纸卡按钮，但危险或重置行为必须先经过确认框。

## 状态与动效

- 默认：米白纸卡、深棕文字、轻微纸张阴影。
- 悬停：边框转为暖黄色，纸卡轻微上移 1–2px。
- 按下：纸卡回落，阴影减弱。
- 键盘聚焦：显示明显的暖黄色外框，不只依赖颜色变化。
- 禁用：灰褐文字与低对比度边框，禁止悬停光效。
- `prefers-reduced-motion: reduce` 时取消纸卡晃动和位移动画，只保留颜色与外框变化。

## 页面布局

```text
右上角：进度图标　静音

中央模块：
        物件 / 档案卡
        说明文字

底部中央：
        [ 主操作 ]
        [ 次操作 ]
```

主操作和次操作保持明确层级；工具按钮不挤入主要叙事区域。所有按钮使用文字说明，图标只作为辅助，例如箭头、耳机和翻页符号。

## 资源与实现边界

- 不新增按钮位图素材。
- 使用 CSS 背景、边框、阴影、下划线和伪元素模拟纸卡边缘。
- 使用现有“小满手写”字体；字体文件继续作为项目资源保留。
- 图标使用内置 SVG 或 CSS 简单图形，不复制外部品牌界面。
- 所有按钮应提供可读的 `aria-label` 或可见文字，并支持 Tab、Enter、Esc。
