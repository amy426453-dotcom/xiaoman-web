> 勾选方法：将 `- [ ]` 改为 `- [x]`。若复制到 Apple 备忘录，可全选后使用“格式 → 清单”转换为原生可点选清单。

## 每项制作要求

以下要求与上面的文件名一一对应。除特别说明外，图片均需提供 PNG 或 WebP；透明物件保留透明背景。

### 场景、参考图与刻度

| 素材 | 制作要求 |
| --- | --- |
| `场景_儿童房背景_默认_桌面.webp` | 1920 × 1080 px；傍晚暖橙色儿童房；白墙、海报、奖状、书桌、床边、窗户和封闭纸箱清晰可见；不要把可独立互动的小物件画死在前景。 |
| `场景_完整合成示意_桌面.webp` | 1920 × 1080 px；把背景、小满、五个区域、物件大小、坐标和遮挡关系完整合成；仅供开发对位，不放进网页。 |
| `场景_身高刻度_默认_桌面.webp` | 独立透明墙面图层；只写 `122 cm / 128 cm / 135 cm / 142 cm / 149 cm / 156 cm`；前五条褪色，最后一条清晰。 |
| `场景_身高刻度_六年级高亮_桌面.webp` | 可选；只高亮 `156 cm`，高亮方式要能与网页光效叠加。 |
