# 《小满的纸箱里，装着整个夏天》音效寻找清单

## 使用规则

- 优先寻找 CC0、Public Domain 或明确允许网页项目使用的音效。
- 每个动作音建议 0.2–1.5 秒；环境声建议无缝循环；剧情人声单独保存。
- 下载后记录来源、作者、许可证和原始链接，最终在项目 README 中署名。
- 所有音效都需要一个可调音量，并支持全局静音。

## 七、应该保留安静的地方

- 全班合照背面文字出现后
- 妈妈喊声结束后
- 黑屏一秒的过渡
- “也是你留下的一件童年”出现时

这些位置只保留极低音量蝉声，或完全静音，让情绪有停顿。
