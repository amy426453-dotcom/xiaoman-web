# 固定模块顺序与热点引导设计

## 目标

将主线固定为“书包 → 电脑 → 抽屉 → MP3 → 纸箱 → 故事结尾”，并用闪烁热点提示当前可进入的下一个模块。

## 规则

- 未到当前阶段的模块热点锁定，不可进入。
- 当前目标热点添加 `is-next` 闪烁状态。
- 已完成模块保留回看能力，但移除闪烁状态。
- 返回房间保留当前进度，不重置模块状态。
- 模块完成并关闭后，恢复房间亮度、解锁并高亮下一模块。
- 电脑内部连连看和农场仍可任意先后完成；只有电脑整体完成后才解锁抽屉。
- 纸箱完成后进入故事结尾，不再高亮模块热点。

## 验收标准

1. 初始只有书包热点闪烁，其他主线模块不可进入。
2. 书包完成后只有电脑热点闪烁。
3. 电脑完成后只有抽屉热点闪烁。
4. 抽屉完成后只有 MP3 热点闪烁。
5. MP3 完成后只有纸箱热点闪烁。
6. 纸箱完成后所有热点停止闪烁并显示结尾引导。
