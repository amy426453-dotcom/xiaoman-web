# 《小满的纸箱里，装着整个夏天》桌面端素材清单

> 对应 PRD：[2026-08-08-xiaoman-childhood-memory-prd.md](2026-08-08-xiaoman-childhood-memory-prd.md)

## 1. 交付总规则

- 清单中的 `.webp` 指网页发布文件；当前 `素材/图片【移除背景】` 目录中的 `.png` 是高质量源素材，不视为缺失文件。
- 源 PNG 保留且不覆盖；网页构建阶段批量导出透明 WebP。若单项压缩后出现白边、透明度异常或文字模糊，则该项继续使用 PNG。
- 当前只准备桌面端，设计基准为 **1920 × 1080 px / 16:9**。
- 核心互动元素应放在中央 **1600 × 900 px** 安全区域内。
- 场景背景优先使用 WebP；透明角色和物件发布时优先使用 WebP，必要时保留 PNG。
- 网页开发以 `素材/图片【移除背景】` 为透明素材的正式来源；`素材/图片` 仅作预览与备份。
- 进度图标最终显示不使用纯白：网页通过 CSS `mask` 将线稿显示为未探索 `#E8D9BE`（45%–55% 透明度）、推荐 `#F2C66D`、进行中 `#F6D58A`、已完成 `#D9903D`；源 PNG 保持白色，不另做着色图片。
- 透明素材四周预留约 10–15% 空白，避免网页缩放时裁切主体。
- 发布文件命名统一为：`区域_物件_状态_桌面.webp`，例如 `书包_密码本_打开_桌面.webp`；源文件可使用同名 `.png`。
- 用户提供手写字体文件（优先 WOFF2）或已获网页使用授权的字体；网页动态排版标题、旁白、纸条和照片背面文字，不需要制作文字图片。
- 7k7k 和 QQ 农场只使用原创拟态界面，不复制官方页面或 Logo。长江七号、喜羊羊、《爆笑校园》、比巴卜、《童年》和手写字体均已确认可用于公开网页；发布前需归档授权凭证。
