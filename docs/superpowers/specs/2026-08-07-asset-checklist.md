# 《小满的纸箱里，装着整个夏天》图片素材清单

## 1. 使用规则

- 图片格式接受 PNG 或 WebP。
- 透明物件建议保留透明背景；背景图保持完整画面。
- 桌面版与移动版背景分别提供，互动热点由网页单独配置。
- `idle` 表示默认状态，`active` 表示被点击/放大状态，`opened` 表示打开状态，`done` 表示完成后的状态。
- 纸箱、全班合照、个人 AI 物件是结尾核心素材，需要优先准备。

## 2. 背景与主角

| 文件名 | 用途 | 需要呈现的效果 |
| --- | --- | --- |
| `bg-room-desktop.webp` | 桌面版房间全景 | 宽画面；白墙、海报、奖状、书桌、床边抽屉、电脑、MP3、窗户、纸箱都可辨认 |
| `bg-room-mobile.webp` | 移动版房间全景 | 竖画面；重新安排主要物件，保证五个热点可见且不被缩得过小 |
| `xiaoman-idle.webp` | 小满默认站立 | 短碎发、白色短袖、卡其色短裤、白色足球长袜，只穿袜子；活泼但停留自然 |
| `xiaoman-walk.webp` | 小满移动到物件旁 | 轻快走动/小跑，适合淡入或位移动画 |
| `xiaoman-look.webp` | 小满观察物件 | 蹲下、弯腰或探头查看，不需要复杂逐帧动作 |
| `xiaoman-listen.webp` | 小满戴 MP3 耳机 | 戴耳机、轻轻晃腿或闭眼听歌 |
| `xiaoman-pack.webp` | 小满整理纸箱 | 双手拿起物件、准备放入纸箱 |
| `xiaoman-turn.webp` | 小满看向窗边 | 过渡事件中从物件转向纸箱/窗户 |

## 6. 不需要提供图片的部分

- 透明玻璃档案卡
- 进度点的灰度/亮起状态
- 物件呼吸光晕
- 物件放大、翻转、掉落、拖拽和收纳动画
- 黑屏停顿与淡入淡出
- 加载条、按钮、输入框和提示文字
- AI 生成结果的纸箱落入动画

## 7. 优先级

### 第一批：可以开始搭建主场景

`bg-room-desktop.webp`、`bg-room-mobile.webp`、`xiaoman-idle.webp`、五个主物件的默认状态图、五个进度图标。

### 第二批：可以完成五段互动

书包全套状态、电脑/桌面状态、抽屉全套物件、MP3/耳机状态、纸箱全套物件。

### 第三批：完成情绪与个人入馆

小满动作状态、标题图、手写参考、全班合照正反面、AI 物件占位和音频素材。
