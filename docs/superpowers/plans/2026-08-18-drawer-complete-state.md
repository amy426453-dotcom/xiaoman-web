# 抽屉完成态素材 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 制作一张保持抽屉打开、在右后方露出同一张全班合照边角的完成态候选 PNG，使“查看六件物品后发现照片”的叙事成立。

**Architecture:** 以现有打开态抽屉作为不可改变的底图，只编辑抽屉内部区域；从纸箱章节的完整合照取材并按抽屉透视嵌入，通过内壁、前板遮挡和接触阴影形成真实层级。先输出独立候选文件，经技术检查与用户视觉确认后才替换正式完成态。

**Tech Stack:** GPT Image 位图编辑、PNG alpha、macOS `sips` 元数据检查、Codex 本地图像查看

---

### Task 1: 生成非破坏性候选图

**Files:**
- Read: `素材/图片【移除背景】/抽屉_书桌抽屉_打开_桌面.png`
- Read: `素材/图片【移除背景】/纸箱_全班合照_正面_桌面.png`
- Read: `素材/图片【移除背景】/抽屉_全班合照_一角_桌面.png`
- Create: `素材/图片【移除背景】/抽屉_书桌抽屉_完成_候选_桌面.png`

- [ ] **Step 1: 记录输入文件的技术规格**

Run:

```bash
sips -g pixelWidth -g pixelHeight -g hasAlpha '素材/图片【移除背景】/抽屉_书桌抽屉_打开_桌面.png' '素材/图片【移除背景】/纸箱_全班合照_正面_桌面.png'
```

Expected: 两个输入均为 `1024 × 1024`，并显示 `hasAlpha: yes`。

- [ ] **Step 2: 使用位图编辑生成候选图**

编辑约束：

```text
将“抽屉_书桌抽屉_打开_桌面.png”作为不可改变的底图。
保持抽屉外框、前板、拉手、导轨、木纹、尺寸、位置、透视、光线和透明背景完全不变。
仅在抽屉内部右后方加入来自“纸箱_全班合照_正面_桌面.png”的同一张旧合照。
照片平放在抽屉底部并符合底板透视，只露出总面积约20%–25%。
可见区域仅包含旧照片白边、暖橙天空和少量蓝白校服；不得出现清晰人脸、实验小学文字、班级和日期。
照片必须被抽屉后侧内壁、右侧内壁和前板自然遮挡，并带有很轻的接触阴影。
抽屉内不保留糖纸、东南西北、泡泡糖、漫画、陀螺或弹珠。
输出1024×1024透明背景PNG。
```

- [ ] **Step 3: 保存为独立候选文件**

Expected: 创建 `抽屉_书桌抽屉_完成_候选_桌面.png`，不修改或覆盖现有 `抽屉_书桌抽屉_完成_桌面.png`。

### Task 3: 用户验收与正式替换
