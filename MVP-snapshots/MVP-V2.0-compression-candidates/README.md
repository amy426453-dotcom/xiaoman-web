# MVP-V2.0 压缩候选素材

此目录是从当前素材库复制出的压缩候选文件，原素材和 V2.0 快照未修改。

## images

使用 Squoosh 处理。透明物品图建议导出 WebP（质量 80–85），并确认透明区域与边缘正常；如不想修改网页引用，可选择 OxiPNG 无损压缩。

## audio

使用本地音频工具处理。BGM 建议重新导出为 MP3，码率 128–160 kbps。压缩后先在本地网页测试，再替换线上 COS 文件。
